# Tahoe Therapeutics

> Tahoe Therapeutics (formerly Vevo Therapeutics) is a South San Francisco digital-biology company building the "ground truth for biological superintelligence." Its Mosaic platform generates perturbative single-cell data in vivo at gigascale, and it trains AI models on the resulting data to discover novel drug targets and predict how patient cells respond to drugs. Tahoe openly publishes large single-cell datasets and model weights, but does not operate a public REST API. Generated by the API Evangelist enrichment pipeline from the public catalog; there is no provider-published llms.txt (/.well-known and /llms.txt return 404).

## Code and Models
- [GitHub organization](https://github.com/tahoebio): Open-source model and research repositories (tahoe-x1, state-tahoe-fork, mosaicfm, sigspace, Biomni-tahoe-fork, scvi-coach).
- [tahoe-x1 on PyPI](https://pypi.org/project/tahoe-x1/): First-party Python package for the Tahoe-x1 single-cell foundation model (`pip install tahoe-x1`, Apache-2.0).
- [Hugging Face organization](https://huggingface.co/tahoebio): Datasets and model weights.
- [Tahoe-100M dataset](https://huggingface.co/datasets/tahoebio/Tahoe-100M): 100-million-cell drug-perturbation single-cell atlas.
- [Tahoe-x1 model](https://huggingface.co/tahoebio/Tahoe-x1): Single-cell foundation model (up to 3B parameters).
- [Rhaister model](https://huggingface.co/tahoebio/Rhaister): Perturbation-response model family.
